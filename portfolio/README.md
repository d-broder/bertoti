## Principais Conhecimentos 📊

- **Linguagens e Frameworks:**
    - `Java` com `Spring Boot` para APIs escaláveis;
    - `Python` com `Django` e `Flask` para web e automação;
    - `React` e `Vue.js` para interfaces modernas;
    - `TypeScript` para tipagem e segurança no front-end.
- **Dados:**
    - `SQL` para modelagem e consultas (`PostgreSQL`, `MySQL`, `Oracle`);
    - `PostGIS` para dados geoespaciais.
- **Metodologias Ágeis (Scrum):**
    - Vivência com Sprints e ferramentas como `Jira` e `Trello`;
    - Transformação de requisitos em User Stories e tarefas técnicas.
- **DevOps e Ferramentas:**
    - `Docker` para conteinerização e padronização de ambientes;
    - `Git` para versionamento e colaboração.
