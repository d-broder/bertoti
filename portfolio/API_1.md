## Resumo do Projeto 📋

Este projeto consiste em uma plataforma web que organiza e explica os processos e artefatos do Scrum de forma clara e acessível. A navegação foi pensada para ser simples e intuitiva, com conteúdo estruturado para facilitar o aprendizado. Ao final de cada módulo, há questionários para validar o conhecimento do usuário.

## Tecnologias Adotadas 💻

- [MySQL](https://www.mysql.com/): SGBD relacional baseado em SQL, usado para armazenar informações estruturadas.
- [HTML](https://html.spec.whatwg.org/multipage/): Linguagem de marcação para estruturar o conteúdo das páginas.
- [CSS](https://www.w3.org/Style/CSS/Overview.en.html): Linguagem de estilo para apresentação e layout visual.
- [Python](https://www.python.org/): Linguagem versátil, aplicada ao back-end da solução.
- [Figma](https://www.figma.com/): Ferramenta para prototipação e design de UI/UX.
- [Trello](https://trello.com/): Gestão das tarefas em quadro Kanban.
- [Flask](https://flask.palletsprojects.com/): Microframework para desenvolvimento web em Python.
- [Git](https://git-scm.com/): Versionamento e colaboração no código.
- [Bootstrap](https://getbootstrap.com/): Biblioteca de componentes para responsividade.

## Contribuições Individuais 🎯

### Atuação como Desenvolvedor Back-end e Front-end

Neste projeto, atuei na montagem das telas e na lógica de avaliação do aprendizado. No front-end, trabalhei com HTML e CSS para criar páginas semânticas e responsivas, alinhadas ao layout definido, com foco em Flexbox para organização do conteúdo em diferentes tamanhos de tela.

No back-end, implementei uma função em Python que recebe o total de acertos do usuário e retorna o resultado do teste com base no desempenho. A lógica calcula a taxa de acerto e determina o nível de conhecimento exibido na tela final.
