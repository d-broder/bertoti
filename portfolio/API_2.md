## Resumo do Projeto 📋

Aplicação que permite ao usuário consultar um banco MySQL usando linguagem natural. A ideia central é converter a pergunta em SQL, executar a consulta e exibir o resultado de forma clara.

## Tecnologias Adotadas 💻

- [Java](https://dev.java/): Linguagem principal do back-end.
- [GitHub](https://github.com/): Hospedagem e colaboração do código.
- [IntelliJ IDEA](https://www.jetbrains.com/idea/): IDE utilizada no desenvolvimento.
- [MySQL](https://www.mysql.com/): Banco de dados relacional do projeto.
- [LangChain4j](https://docs.langchain4j.dev/): Integração com LLMs em Java.
- [Ollama](https://ollama.com/): Execução local de modelos de linguagem.
- [LM Studio](https://lmstudio.ai/): Gerenciamento e testes de LLMs locais.

## Contribuições Individuais 🎯

### Atuação como Desenvolvedor Back-end

Meu foco foi a infraestrutura do back-end e a integração com IA. Estruturei a conexão com o banco e a ponte de comunicação entre a aplicação e o LLM. Também participei da fase de testes técnicos, avaliando executores de modelos para definir a arquitetura mais eficiente.

Implementei a funcionalidade para escolher e alternar modelos de linguagem locais. Dessa forma, o usuário pode ajustar a IA conforme a capacidade de hardware disponível.
